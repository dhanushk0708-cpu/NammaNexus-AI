# NammaNexus AI

## Project Title

NammaNexus AI — An AI-Powered Civic Intelligence Platform for Bengaluru

## Project Purpose

NammaNexus AI is a college and portfolio project designed to explore how artificial intelligence, computer vision, geospatial data, large language models, and intelligent service orchestration can be combined to build a civic intelligence platform for Bengaluru.

The platform consists of four connected pillars:

1. SpotFix AI
2. CivicVoice AI
3. SafeStreet AI
4. CivicAssist AI

## Current Development Focus

The project will be developed incrementally.

The first pillar to be implemented is:

SpotFix AI

## Development Principle

The project will not be developed using blind AI-generated code.

Every major component will be understood, implemented, tested, and documented before moving to the next component.

AI coding agents may be used for large implementation tasks, but the architecture, code flow, dependencies, and design decisions must be understood by the developer.

## Performance Principle

AI will only be used where it provides meaningful value.

Deterministic operations such as database lookups, ward identification, authority lookup, validation, and routing rules should not unnecessarily use an LLM.

Independent operations should be executed in parallel where appropriate.

Non-critical operations should use background processing where appropriate.

## AI Models

Gemini Vision:
Used primarily for image understanding and civic issue detection.

Groq-hosted LLMs:
Used primarily for fast text-based AI tasks.
